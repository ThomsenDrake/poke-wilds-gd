# PokeWilds Strategy

## Purpose

Players who want to live in an open Pokémon survival sandbox — no gyms, no trainers, no Centers — never got that from the official games. The one fan game that shipped the fantasy (SheerSt's PokeWilds) froze in public alpha.

## Positioning

Rebuild PokeWilds from the ground up in Godot — no reused GDX — because the original's public game stopped and Godot's adoption is better for players and, later, modders. Ship to playtesters first; the harness is already live and is not the product.

## Users

**Primary:** Players - They're hiring PokeWilds to live in an open Pokémon survival sandbox the official games don't offer.

## Boundaries

- Don't freeze the sandbox for another month of packaging and updates.
- Don't build a mod API before the sandbox is worth extending.
- Don't treat the harness as the product.
- Don't build multiplayer now — leave room for it later.

_Resist a change when:_ it starves the sandbox, fronts modders before players, treats the harness as the product, or pulls work into multiplayer before the single-player game is what players hired.

## Key metrics

- **Playtest hours** - Time testers actually spend in the sandbox; lives in playtester feedback.
- **Incoming bug reports** - Defects testers send back; lives in playtester feedback.
- **Early bounce** - A quit around ten minutes is a useful signal; not instrumented yet, inferred from reports.
- **Feature-parity remaining** - How much of the original single-player sandbox is still missing; lives in the feature audit / completion plan, not a live dashboard.

## Tracks

### Sandbox loop

The open Pokémon survival gameplay — harvest, build, camp, craft, fish, breed, overworld mons, landmarks, dungeons.

_Why it serves the approach:_ The player situation is the point; this is the game they hired.

### Distribution

Builds, updates, and the playtest feedback channel so players can get the game and talk back.

_Why it serves the approach:_ Godot only helps if players can actually run a living build.

## Brand

**One-liner:** Pokémon as an open survival sandbox the official games never shipped.
