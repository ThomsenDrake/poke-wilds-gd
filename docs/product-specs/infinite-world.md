The world is ONE SEAMLESS INFINITE PROCEDURAL PLANE. `world_generator.get_tile_logic` computes any coordinate forever — the noise plane was ALWAYS unbounded; the bounded disc only ever lived in the chain predicates, and the infinite-world arc (slices 1-4, 2026-08-02..03) deleted them. ## Climate-field biomes (slice 2)

`scripts/domain/biome_field.gd` is the ONE shared source for "what biome is this tile". It collapsed the THREE verbatim mirrors the radial model was pasted into (`world_generator._pick_biome` + `_ring_candidates`, `legendary_placement._biome_from` + `_ring_candidates`, `landmarks._elevation_noise`), so mirror drift is impossible by construction. The radial model assigned land biomes by Manhattan-distance rings (candidates at 10/28/60); the climate model derives them from continuous fields, so EVERY biome has nonzero measure anywhere on the seamless plane.

- **The four channels** (`make_channels(seed)`, the ONE factory — every frequency/salt lives here; low frequencies → broad regions, not salt-and-pepper; salts continue the additive-salt convention):
  - **elevation** — seed, frequency 0.010, 4 octaves, gain 0.45. UNCHANGED from the radial model (`elevation_noise` single-sourced), so landmark anchors + coastlines are byte-identical across the model swap; `landmarks._fits_on_land` + `is_rock_cliff` ride it.
  - **temperature** — seed + 7919, frequency 0.006, 2 octaves, gain 0.50 (hot/cold axis).
  - **moisture** — seed + 104729, frequency 0.007, 2 octaves, gain 0.50 (wet/dry axis).
  - **volcanism** — seed + 4242, frequency 0.004, 2 octaves, gain 0.50 (REUSES the retired radial biome channel as the rare-volcanic mask).
- **The priority table** (`biome_from_e(channels, tile, e)`; the ORDER is load-bearing — elevation gates first, then temperature, then moisture; every threshold is a FLAGGED invention calibrated against the world-gen audit's biome-distribution measurement):
  1. `e < -0.30` (`WATER_ELEVATION`) → WATER.
  2. `e < -0.12` (`SAND_ELEVATION`) → SAND (the beach band).
  3. `e >= 0.45` (`ROCK_BIOME_ELEVATION`) → ROCK (elevation > 0.55 still gets the smash cliff prop).
  4. `t < -0.35` (`SNOW_TEMP`) → SNOW.
  5. `t > 0.40` (`LAVA_TEMP`) ∧ `m < -0.15` (`LAVA_MOIST`) ∧ `v > 0.40` (`LAVA_VOLCANIC`) → LAVA.
  6. `t >= 0.15` (`DESERT_TEMP`) ∧ `m < -0.20` (`DRY_MOIST`) → DESERT.
  7. `t >= 0.15` ∧ `m < 0.05` (`ARID_MOIST`) → SAVANNA.
  8. `m >= 0.40` (`WET_MOIST`) → SWAMP.
  9. `m >= 0.10` (`FOREST_MOIST`) ∧ `t >= -0.10` (`COOL_TEMP`) → FOREST.
  10. `m >= -0.20` ∧ `t >= -0.10` → GRASSLAND.
  11. else PLAINS (the cool/dry fallback steppe).

  `KNOWN_BIOMES` is the closed 11-biome set (`biome_defs.gd`'s keys).
- **WATER / SAND / ROCK stay elevation-driven** — coastlines, beaches, and mountains are MODEL-INVARIANT (same elevation channel, same gates as the radial model), which is what keeps the slice-4 beach spawn and the landmark land test riding unchanged seams.
- **LAVA is the rare joint tail of three independent fields** — nonzero measure everywhere on the plane, never a quantization accident. This RESOLVED the radial model's gap (LAVA was candidate index 8 of 9 at ring ≥ 60 and the biome noise never reached region ≥ 0.889 — the legendary EMPIRICAL FLAG): LAVA now measures ~0.02-0.9% of tiles per seed, present in 8 of the audit's 9 windows. A cold-climate window may legitimately lack it, so presence is enforced ONLY cross-seed (`LAVA_WINDOWS_MIN := 6` of the 9 audit windows), never per-seed.

## Save v6 (slice 1)

`SAVE_VERSION := 6` (`session_state.gd`) retires the v5 chaining shape for one plane; `save_migration.gd` stays PURE (deep-copy — never mutates its argument; the schema constant is passed as an argument to avoid a preload cycle).

- **Chain-less v4/v5 saves flatten LOSSLESSLY.** `migrate(payload, 6)` brings a v4/absent-version payload to v5 shape (adds `root_seed` / `active_chain := "0,0"` / `chained_worlds`, nesting a top-level `landmark_state` under `chained_worlds["0,0"]`), then flattens v5 → v6: drops all three chain keys and hoists the origin `landmark_state` back to its top-level seat — the exact inverse of the v5 relocation. Net: the delta on a chain-less save is EXACTLY `{version: 6}` (the pinned byte witnesses in `byte_witness_issues` prove this against the golden v4 fixture, plus the argument-untouched and no-surviving-chain-key asserts). The origin world's seed was always the root seed itself (the retired chain module's frozen `world_seed_for(root,(0,0))==root` identity), so a flattened save's `world_seed` is byte-identical and its visible terrain does not shift.
- **Truly chained v5 saves are REFUSED non-destructively.** A payload with `active_chain != "0,0"` OR a non-origin `chained_worlds` entry is structurally unrepresentable on one plane (`can_represent_infinite` / `can_downshift`). The load path (`game_runtime.ensure_initialized`) gates on this and REFUSES: the save is preserved to `.chained.bak` (miss-002 loud; `_preserve` arms live-path protection so the autosave can never clobber it) and a fresh game starts — never a destructive flatten.
- **`normalize_instance_keys` rewrites legacy keys losslessly.** Legacy BARE `landmark_state` ids (`"pkmn_mansion"`) re-key to per-instance `"id@ax,ay"` via `Landmarks.anchor_for(seed, origin, id)`, and frozen `"0,0:<SPECIES>"` removal keys re-key to the origin anchor `"<ax>,<ay>:<SPECIES>"` via `legendaries_for_world(seed, origin)` — both derived from the payload's OWN `world_seed` (the canonical origin derivations are removal-independent, so a load-time derivation matches every runtime re-derivation). Unknown keys survive verbatim; the pass is idempotent and rides the v6 pass-through too.

## Determinism

- **FastNoiseLite is (seed, x, y)-pure.** All four climate channels re-derive identically from the seed; there is no per-frame or per-process state in the field.
- **Every scatter roll rides `overworld_mons._mix` SplitMix** — explicit sub-`INT64_MAX` constants + 63-bit masks, int64 multiply-wrap; NO engine `hash()`, NO dict iteration. Salts are distinct per stream (§ Chunk-hash content scattering).
- **NO `RandomNumberGenerator` in domain.** The `check_repo_contracts.py` ban covers `scripts/domain/**` + the world-depth runtime (`landmark_runtime`); the three legitimate owners (`game_runtime` / `battle_runtime` / `player_avatar`) live OUTSIDE that scope, so the ban needs no allowlist; the ONLY world-seed draw is the pinned `new_game` `randi` (or the custom-seed bypass). The shared `_rng` encounter stream + the pinned double-run consumers stay untouched.
- **Window-bounded enumeration — never the plane.** `chunks_in_window`, the landmark scatter cache (`CHUNK_CACHE_CAP := 256`, insertion-order eviction), and every audit scan (`disc_positions`, the stride-sampled distribution window, the chunk-ring density sample) are bounded by construction; an infinite walk grows nothing.
